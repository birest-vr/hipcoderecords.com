# hipcoderecords.com

Sito ufficiale di Hip Code Records (Verona).

- `index.html` — pagina del sito
- `assets/` — loghi e copertine
- `assets/releases.js` — catalogo (generato)
- `tools/build_releases.py` — aggiunge un disco dal foglio AmpSuite + copertina:
  `python3 tools/build_releases.py HIPC0XX=foglio.xlsx:copertina.jpg`
